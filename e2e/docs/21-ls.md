# Listing Branches

The `sc ls` command shows all tracked branches as a tree.

## No Tracked Branches

When there are no tracked branches, a message is displayed:

```console
$ sc ls
No tracked branches found.
```

## Single Branch

Create a single tracked branch and list it:

```console
$ echo "hello" > hello.py && git add hello.py
$ sc create -m "Add hello module"
Created branch 'add-hello-module' from 'main'
$ sc ls
◉ add-hello-module (current)
│ Add hello module
│
◯ main
  Initial commit
```

## JSON Output

For scripts and agents, `sc ls --json` emits the stack as a single JSON document.
Each branch lists its parent, so the stack can be rebuilt without parsing the tree glyphs:

```console
$ sc ls --json
{"data": {"branches": [{"name": "main", "parent": null, "current": false, "pr": null, "commit_subject": "Initial commit", "worktrees": [], "warning": null, "needs_restack": false}, {"name": "add-hello-module", "parent": "main", "current": true, "pr": null, "commit_subject": "Add hello module", "worktrees": [], "warning": null, "needs_restack": false}], "current": "add-hello-module"}}
```

## Stacked Branches

Create a stack of branches and verify the tree output:

```console
$ echo "world" > world.py && git add world.py
$ sc create -m "Add world module"
Created branch 'add-world-module' from 'add-hello-module'
$ sc ls
◉ add-world-module (current)
│ Add world module
│
◯ add-hello-module
│ Add hello module
│
◯ main
  Initial commit
```

Add a third level to the stack:

```console
$ echo "utils" > utils.py && git add utils.py
$ sc create -m "Add utils module"
Created branch 'add-utils-module' from 'add-world-module'
$ sc ls
◉ add-utils-module (current)
│ Add utils module
│
◯ add-world-module
│ Add world module
│
◯ add-hello-module
│ Add hello module
│
◯ main
  Initial commit
```

## Forked Branches

Create two branches from the same parent to form a fork:

```console
$ git checkout add-hello-module
$ echo "fork a" > fork_a.py && git add fork_a.py
$ sc create -m "Add fork A"
Created branch 'add-fork-a' from 'add-hello-module'
$ git checkout add-hello-module
$ echo "fork b" > fork_b.py && git add fork_b.py
$ sc create -m "Add fork B"
Created branch 'add-fork-b' from 'add-hello-module'
$ sc ls
◯ add-fork-a
│ Add fork A
│
│ ◉ add-fork-b (current)
│ │ Add fork B
│ │
│ │ ◯ add-utils-module
│ │ │ Add utils module
│ │ │
│ │ ◯ add-world-module
│ │ │ Add world module
│ │ │
◯─┴─┘ add-hello-module
│     Add hello module
│
◯ main
  Initial commit
```
